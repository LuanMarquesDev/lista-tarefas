# Lista de Tarefas ✅

Projeto simples de lista de tarefas com **frontend** e **backend**.

## 🚀 Tecnologias
- .NET (C#) no backend  
- HTML, CSS e JS no frontend  

## 📂 Estrutura
```
lista-tarefas/
├── back-end/     # API em .NET
└── front-end/    # Interface web
```

## ▶️ Como rodar

### Backend
```bash
cd back-end
dotnet run
```

### Frontend
```bash
cd front-end
# se usar npm/yarn
npm install
npm start
```

## 📌 Funcionalidades
- Adicionar tarefas  
- Listar tarefas  
- Editar tarefas  
- Excluir tarefas
